pub:            "Nature Communications"

abstract: >-
  Tree-based models such as Random Forest excel in interpretability and accuracy for tabular data,
  but scaling them on hardware is hard because sharp decision boundaries are highly susceptible to
  device variations. We present a hardware-software co-design using MoS2 flash-based analog
  content-addressable memory with inherent soft boundaries, enabling efficient and trustworthy
  inference with soft tree-based models.
